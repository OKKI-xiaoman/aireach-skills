
## 🔌 AiReach 获客能力插件集(AiReach-Skills)

Skill Lab 是将 AiReach 验证成熟的专业获客能力，逐步开放为单点 Skill 的实验室。通用 Agent 通常只能抓取公开网站信息，而通过 Skill Lab，可以在通用 Agent 框架中灵活调用 AiReach 的深层数据与校验能力，实现更精准的潜客开发，目前 Skill Lab 能力仅 AiReach 付费商家可使用。

## 💻 支持平台

支持主流通用 Agent 平台，包括但不限于：
*   **Accio Work**
*   **Workbuddy**
*   **Qoderwork**
*   **Codex** (注：海外产品可能对邮箱、联系方式等敏感信息有风控限制，影响部分效果)

## 🚀 安装与使用

### 1. Accio Work 平台
请直接在插件市场安装最新版的 **OKKI AiReach** 插件。登录 OKKI 账号后即可在智能体中直接调用上述 Skill。

> **操作路径：** 智能体 -> 插件 -> 市场 -> 搜索 "OKKI AiReach" -> 安装并授权。

### 2. 其他通用 Agent 平台
通过复制 Skill Lab 后台提供的 **GitHub 链接**，直接发送给通用 Agent 进行安装即可。

## 💰 收费方式

*   **限时优惠：** 当前阶段提供一定次数的限时免费使用。
*   **后续计划：** 后续将根据能力的复杂度，依据消耗的“工时”点数进行计费。
*   **具体标准：** 最终收费起始时间及消耗标准请以 Skill Lab 后台实时显示为准。
